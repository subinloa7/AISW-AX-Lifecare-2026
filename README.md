## 01. Project Overview

**AI 소비 패턴 분석 가계부**는 사용자의 소비 내역을 입력받아 소비 패턴을 분석하고, 합리적인 소비 습관을 형성할 수 있도록 돕기 위해 제작한 웹 프로젝트입니다.

단순한 지출 기록을 넘어 소비 데이터를 바탕으로 자신의 소비 습관을 파악하고 개선하는 것을 목표로 합니다.

| 구분 | 내용 |

| 개발 형태 | Web Application |
| 개발 단계 | MVP |
| 개발 언어 | HTML, CSS, JavaScript |

---

## 02. Main Features

### 소비 내역 입력
사용자의 소비 내역을 입력하고 관리합니다.

### 소비 데이터 분석
입력된 소비 데이터를 기반으로 소비 패턴을 분석합니다.

### 소비 패턴 확인
자신의 소비 습관과 지출 현황을 확인할 수 있습니다.

### 소비 습관 개선
소비 데이터를 통해 합리적인 소비 습관을 형성하도록 돕습니다.

## 05. How to Run

1. GitHub Repository에서 프로젝트 파일을 다운로드합니다.
2. `index.html` 파일을 브라우저에서 실행합니다.
3. 소비 내역을 입력합니다.
4. 소비 패턴 분석 기능을 이용합니다.
