# AI 소비 패턴 분석 가계부

AISW페스티벌 2026 | AX 라이프케어 챌린지 출품 프로젝트

1. 프로젝트 소개
AI를 활용하여 개인의 소비 내역을 입력하고 소비 패턴을 분석할 수 있도록 제작한 웹 기반 가계부 프로젝트입니다.

단순한 지출 기록을 넘어 자신의 소비 습관을 파악하고 합리적인 소비를 할 수 있도록 돕는 것을 목표로 합니다.
2. 프로젝트 정보

참가 분야	AX 라이프케어 챌린지
개발 형태	웹 애플리케이션

3. 주요 기능
- 소비 내역 입력
- 입력된 소비 데이터 기반 분석
- 소비 패턴 확인
- 소비 습관 개선을 위한 정보 제공
4. 기술 스택
- HTML
- CSS
- JavaScript

6. 실행 방법
1. Repository에서 index.html 파일을 다운로드합니다.
2. 다운로드한 파일을 브라우저에서 실행합니다.
3. 소비 내역을 입력합니다.
4. 소비 패턴 분석 기능을 이용합니다.
7. 프로젝트를 통해 배운 점
- HTML, CSS, JavaScript를 활용한 웹 개발 경험
- 사용자 입력 데이터 처리 및 분석 과정 이해
- 아이디어를 실제 웹 애플리케이션으로 구현하는 경험
- 프로젝트 기획부터 구현까지의 개발 과정 경험
8. 향후 개선 방향
- 소비 데이터 저장 기능
- CSV 파일 업로드 기능
- 소비 패턴 시각화 및 그래프 개선
- AI 기반 소비 분석 및 리포트 기능
